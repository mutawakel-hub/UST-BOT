    26→## 1. نظرة عامة على المشروع
    27→
    28→### 1.1 الهدف
    29→بناء نظام بوت تلغرام مركزي لجامعة العلوم والتكنولوجيا، يخدم آلاف الطلاب للوصول إلى المحتوى الأكاديمي (مقررات، نماذج، ملخصات)، مع نظام مساهمات طلابي ولوحة إدارة هرمية من 4 مستويات.
    30→
    31→### 1.2 المكوّنات الرئيسية
    32→
    33→| المكوّن | الوصف |
    34→|---|---|
    35→| 🎓 **بوت الطالب** | 12 شاشة أساسية لتصفح المحتوى والمساهمة والاشتراكات |
    36→| 🛡 **بوت الإدارة** | 15 شاشة إدارية مع 4 أدوار هرمية |
    37→| 🗄 **قاعدة البيانات** | Supabase (PostgreSQL) — 10 جداول أساسية |
    38→| 📦 **التخزين** | 7 قنوات تلغرام خاصة (قناة لكل كلية) |
    39→| ⚡ **الـ Runtime** | Cloudflare Workers (مجاني 100%) |
    40→
    41→### 1.3 المبادئ التصميمية
    42→
    43→- **صفر تكلفة:** جميع الخدمات ضمن الباقات المجانية
    44→- **أداء عالٍ:** استجابة < 500ms لكل طلب
    45→- **أمان مزدوج:** فحص الصلاحية في الواجهة والباك إند
    46→- **تخصيص كامل:** جميع النصوص والأزرار قابلة للتعديل من الإدارة
    47→- **بساطة الطالب:** تدفق مباشر من 6 خطوات للوصول لأي ملف

    51→## 2. التقنيات المؤكدة
    52→
    53→| الطبقة | التقنية | السبب |
    54→|---|---|---|
    55→| Runtime | **Cloudflare Workers** | 100k طلب/يوم مجاناً + استجابة فورية |
    56→| لغة البرمجة | **TypeScript** | أمان الأنواع + إنتاجية عالية |
    57→| مكتبة تلغرام | **grammY** | مصممة لـ Serverless + دعم Webhooks |
    58→| قاعدة البيانات | **Supabase (PostgreSQL)** | 500MB مجاناً + REST API + PgBouncer |
    59→| التخزين المؤقت | **Cloudflare KV** | للجلسات و Rate Limiting |
    60→| طوابير الإرسال | **Cloudflare Queues** | للتعميمات الجماعية |
    61→| تخزين الملفات | **7 قنوات تلغرام** | مجاني وغير محدود |
    62→| إدارة الحزم | **pnpm** | سريع وفعال |
    63→| CI/CD | **GitHub Actions** | نشر تلقائي على Cloudflare |

    69→## 3. القرارات التشغيلية النهائية
    70→
    71→تم تأكيد القرارات التالية مع العميل:
    72→
    73→| البند | القرار |
    74→|---|---|
    75→| التحقق من هوية الطلاب | ❌ غير مطلوب — البوت مفتوح للجميع |
    76→| تخزين الملفات | ✅ قناة منفصلة لكل كلية (7 قنوات) |
    77→| الشارات (Badges) | ❌ ملغاة |
    78→| استرداد الحساب | ❌ ملغى |
    79→| النسخ الاحتياطي | ❌ ملغى مؤقتاً |
    80→| اللغة | 🇸🇦 عربي فقط (RTL) |
    81→| لوحة ويب للإدارة | ❌ يكفي بوت الإدارة |
    82→| تخصيص النصوص | ⚡ فوري + مركزي + كلية فقط |
    83→| لوحة الشرف | 🔄 يحدّثها المسؤول المركزي |
    84→| التعميمات | 📢 كل الأنواع (نص + صورة + ملف) حسب الصلاحية |
    85→| الأدوار الإدارية | 👥 4 مستويات هرمية |

   292→## 5. تصميم قاعدة البيانات
   293→
   294→### 5.1 المخطط الكامل (10 جداول)
   295→
   296→```sql
   297→-- ============================================
   298→-- 1. الكليات (7 صفوف ثابتة)
   299→-- ============================================
   300→CREATE TABLE colleges (
   301→  id SERIAL PRIMARY KEY,
   302→  name TEXT NOT NULL,
   303→  name_normalized TEXT NOT NULL,  -- للبحث
   304→  channel_id TEXT,                -- معرّف قناة تخزين الكلية
   305→  committee_channel_url TEXT,     -- رابط قناة اللجنة العلمية
   306→  display_order INT DEFAULT 0,
   307→  is_active BOOLEAN DEFAULT true,
   308→  created_at TIMESTAMP DEFAULT NOW()
   309→);
   310→CREATE INDEX idx_colleges_normalized ON colleges(name_normalized);
   311→
   312→-- ============================================
   313→-- 2. التخصصات
   314→-- ============================================
   315→CREATE TABLE specialties (
   316→  id SERIAL PRIMARY KEY,
   317→  college_id INT NOT NULL REFERENCES colleges(id) ON DELETE CASCADE,
   318→  name TEXT NOT NULL,
   319→  name_normalized TEXT NOT NULL,
   320→  levels_count INT NOT NULL DEFAULT 4,  -- عدد المستويات
   321→  is_active BOOLEAN DEFAULT true,
   322→  created_at TIMESTAMP DEFAULT NOW()
   323→);
   324→CREATE INDEX idx_specialties_college ON specialties(college_id);
   325→
   326→-- ============================================
   327→-- 3. المستويات (محسوبة ديناميكياً، لا جدول مستقل)
   328→-- (يتم توليدها من specialties.levels_count)
   329→-- ============================================
   330→
   331→-- ============================================
   332→-- 4. المواد الدراسية
   333→-- ============================================
   334→CREATE TABLE subjects (
   335→  id SERIAL PRIMARY KEY,
   336→  specialty_id INT NOT NULL REFERENCES specialties(id) ON DELETE CASCADE,
   337→  level INT NOT NULL,                    -- 1..6 حسب التخصص
   338→  semester INT NOT NULL CHECK (semester IN (1, 2)),
   339→  name TEXT NOT NULL,
   340→  name_normalized TEXT NOT NULL,
   341→  is_active BOOLEAN DEFAULT true,
   342→  created_at TIMESTAMP DEFAULT NOW()
   343→);
   344→CREATE INDEX idx_subjects_specialty ON subjects(specialty_id, level, semester);
   345→CREATE INDEX idx_subjects_search ON subjects USING GIN (name_normalized gin_trgm_ops);
   346→
   347→-- ============================================
   348→-- 5. الملفات (المحتوى الفعلي)
   349→-- ============================================
   350→CREATE TABLE files (
   351→  id BIGSERIAL PRIMARY KEY,
   352→  subject_id INT NOT NULL REFERENCES subjects(id) ON DELETE CASCADE,
   353→  category TEXT NOT NULL CHECK (category IN ('book_theory', 'book_practical', 'exam', 'summary')),
   354→  file_name TEXT NOT NULL,
   355→  file_id TEXT NOT NULL,                 -- معرّف تلغرام
   356→  file_unique_id TEXT NOT NULL,          -- معرّف فريد تلغرام
   357→  file_hash VARCHAR(64) UNIQUE NOT NULL, -- منع التكرار (SHA-256)
   358→  file_size BIGINT,
   359→  mime_type TEXT,
   360→  uploaded_by_admin_id INT,              -- NULL يعني مساهمة طالب
   361→  contribution_id BIGINT,                -- ربط بالمساهمة إن وجدت
   362→  is_starred BOOLEAN DEFAULT false,      -- محتوى مميز
   363→  download_count INT DEFAULT 0,
   364→  created_at TIMESTAMP DEFAULT NOW()
   365→);
   366→CREATE INDEX idx_files_subject ON files(subject_id, category);
   367→CREATE INDEX idx_files_hash ON files(file_hash);
   368→
   369→-- ============================================
   370→-- 6. المستخدمون (الطلاب)
   371→-- ============================================
   372→CREATE TABLE users (
   373→  id BIGSERIAL PRIMARY KEY,
   374→  telegram_id BIGINT UNIQUE NOT NULL,
   375→  username TEXT,
   376→  first_name TEXT,
   377→  last_name TEXT,
   378→  current_college_id INT,        -- للاستخدام في "حسابي"
   379→  current_specialty_id INT,
   380→  current_level INT,
   381→  total_downloads INT DEFAULT 0,
   382→  accepted_contributions INT DEFAULT 0,
   383→  is_blocked BOOLEAN DEFAULT false,
   384→  last_activity TIMESTAMP DEFAULT NOW(),
   385→  created_at TIMESTAMP DEFAULT NOW()
   386→);
   387→CREATE INDEX idx_users_telegram ON users(telegram_id);
   388→
   389→-- ============================================
   390→-- 7. المساهمات (في انتظار المراجعة)
   391→-- ============================================
   392→CREATE TABLE contributions (
   393→  id BIGSERIAL PRIMARY KEY,
   394→  user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
   395→  subject_id INT NOT NULL REFERENCES subjects(id),
   396→  category TEXT NOT NULL,
   397→  file_name TEXT NOT NULL,
   398→  file_id TEXT NOT NULL,
   399→  file_hash VARCHAR(64) NOT NULL,
   400→  description TEXT,
   401→  status TEXT NOT NULL DEFAULT 'pending'
   402→    CHECK (status IN ('pending', 'approved', 'rejected')),
   403→  is_starred BOOLEAN DEFAULT false,
   404→  reject_reason TEXT,
   405→  reviewed_by_admin_id INT,
   406→  reviewed_at TIMESTAMP,
   407→  escalation_level INT DEFAULT 0,  -- 0, 1 (24h), 2 (48h)
   408→  created_at TIMESTAMP DEFAULT NOW()
   409→);
   410→CREATE INDEX idx_contributions_status ON contributions(status, created_at);
   411→CREATE INDEX idx_contributions_subject_hash ON contributions(subject_id, file_hash);
   412→
   413→-- ============================================
   414→-- 8. المسؤولون (4 أدوار هرمية)
   415→-- ============================================
   416→CREATE TABLE admins (
   417→  id SERIAL PRIMARY KEY,
   418→  telegram_id BIGINT UNIQUE NOT NULL,
   419→  name TEXT NOT NULL,
   420→  role TEXT NOT NULL CHECK (role IN ('central', 'college', 'specialty', 'level')),
   421→  college_id INT REFERENCES colleges(id),         -- لـ college/specialty/level
   422→  specialty_id INT REFERENCES specialties(id),    -- لـ specialty/level
   423→  level INT,                                       -- لـ level فقط
   424→  is_active BOOLEAN DEFAULT true,
   425→  created_at TIMESTAMP DEFAULT NOW(),
   426→  -- ضمان النطاق حسب الدور
   427→  CONSTRAINT chk_admin_scope CHECK (
   428→    (role = 'central' AND college_id IS NULL AND specialty_id IS NULL AND level IS NULL) OR
   429→    (role = 'college' AND college_id IS NOT NULL AND specialty_id IS NULL AND level IS NULL) OR
   430→    (role = 'specialty' AND college_id IS NOT NULL AND specialty_id IS NOT NULL AND level IS NULL) OR
   431→    (role = 'level' AND college_id IS NOT NULL AND specialty_id IS NOT NULL AND level IS NOT NULL)
   432→  )
   433→);
   434→CREATE INDEX idx_admins_telegram ON admins(telegram_id);
   435→
   436→-- ============================================
   437→-- 9. اشتراكات الطلاب في المواد
   438→-- ============================================
   439→CREATE TABLE subscriptions (
   440→  id BIGSERIAL PRIMARY KEY,
   441→  user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
   442→  subject_id INT NOT NULL REFERENCES subjects(id) ON DELETE CASCADE,
   443→  created_at TIMESTAMP DEFAULT NOW(),
   444→  UNIQUE(user_id, subject_id)
   445→);
   446→CREATE INDEX idx_subscriptions_subject ON subscriptions(subject_id);
   447→
   448→-- ============================================
   449→-- 10. النصوص والأزرار القابلة للتخصيص
   450→-- ============================================
   451→CREATE TABLE custom_texts (
   452→  id SERIAL PRIMARY KEY,
   453→  screen_key TEXT NOT NULL,           -- مثل 'main_menu', 'choose_college'
   454→  text_key TEXT NOT NULL,             -- مثل 'welcome_message', 'btn_colleges'
   455→  default_value TEXT NOT NULL,
   456→  custom_value TEXT,                  -- NULL يعني استخدم الافتراضي
   457→  scope_type TEXT NOT NULL DEFAULT 'global'
   458→    CHECK (scope_type IN ('global', 'college')),
   459→  scope_college_id INT,               -- NULL للنطاق العام
   460→  updated_by_admin_id INT,
   461→  updated_at TIMESTAMP DEFAULT NOW(),
   462→  UNIQUE(screen_key, text_key, scope_type, scope_college_id)
   463→);
   464→
   465→-- ============================================
   466→-- 11. سجل العمليات الإدارية (Audit Log)
   467→-- ============================================
   468→CREATE TABLE audit_logs (
   469→  id BIGSERIAL PRIMARY KEY,
   470→  admin_id INT NOT NULL REFERENCES admins(id),
   471→  action TEXT NOT NULL,               -- 'approve', 'reject', 'upload', 'delete', 'broadcast'...
   472→  entity_type TEXT,                   -- 'file', 'contribution', 'admin', 'subject'...
   473→  entity_id BIGINT,
   474→  details JSONB,
   475→  created_at TIMESTAMP DEFAULT NOW()
   476→);
   477→CREATE INDEX idx_audit_admin ON audit_logs(admin_id, created_at);
   478→CREATE INDEX idx_audit_action ON audit_logs(action, created_at);
   479→
   480→-- ============================================
   481→-- 12. التحميلات (لسجل الطالب + الإحصائيات)
   482→-- ============================================
   483→CREATE TABLE downloads (
   484→  id BIGSERIAL PRIMARY KEY,
   485→  user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
   486→  file_id BIGINT NOT NULL REFERENCES files(id) ON DELETE CASCADE,
   487→  created_at TIMESTAMP DEFAULT NOW()
   488→);
   489→CREATE INDEX idx_downloads_user ON downloads(user_id, created_at DESC);
   490→CREATE INDEX idx_downloads_file ON downloads(file_id);
   491→
   492→-- ============================================
   493→-- 13. التعميمات (للسجل + منع التكرار)
   494→-- ============================================
   495→CREATE TABLE broadcasts (
   496→  id BIGSERIAL PRIMARY KEY,
   497→  admin_id INT NOT NULL REFERENCES admins(id),
   498→  scope_type TEXT NOT NULL CHECK (scope_type IN ('all', 'college', 'specialty', 'level')),
   499→  scope_college_id INT,
   500→  scope_specialty_id INT,
   501→  scope_level INT,
   502→  content_type TEXT NOT NULL CHECK (content_type IN ('text', 'photo', 'document')),
   503→  text_content TEXT,
   504→  media_file_id TEXT,
   505→  sent_count INT DEFAULT 0,
   506→  failed_count INT DEFAULT 0,
   507→  status TEXT DEFAULT 'queued' CHECK (status IN ('queued', 'sending', 'completed', 'failed')),
   508→  created_at TIMESTAMP DEFAULT NOW()
   509→);
   510→
   511→-- ============================================
   512→-- 14. لوحة الشرف (مخزّنة + يحدّثها المركزي)
   513→-- ============================================
   514→CREATE TABLE leaderboard (
   515→  id BIGSERIAL PRIMARY KEY,
   516→  user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
   517→  scope_type TEXT NOT NULL CHECK (scope_type IN ('global', 'college', 'specialty')),
   518→  scope_college_id INT,
   519→  scope_specialty_id INT,
   520→  rank INT NOT NULL,
   521→  points INT NOT NULL,
   522→  period_start DATE,
   523→  period_end DATE,
   524→  updated_at TIMESTAMP DEFAULT NOW(),
   525→  UNIQUE(user_id, scope_type, scope_college_id, scope_specialty_id, period_start)
   526→);
   527→CREATE INDEX idx_leaderboard_scope ON leaderboard(scope_type, scope_college_id, scope_specialty_id, rank);
   528→```

   762→## 9. الأمان والأداء
   763→
   764→### 9.1 الأمان
   765→
   766→| الإجراء | التطبيق |
   767→|---|---|
   768→| ✅ التحقق المزدوج من الصلاحية | Frontend (إخفاء الأزرار) + Backend (فحص فعلي) |
   769→| ✅ Rate Limiting ثلاثي الطبقات | Durable Object + KV + IP |
   770→| ✅ Audit Log شامل | جدول `audit_logs` لكل عملية إدارية |
   771→| ✅ منع الملفات المكررة | `file_hash` UNIQUE constraint |
   772→| ✅ فحص نوع الملف (Magic Bytes) | لا الاعتماد على الامتداد فقط |
   773→| ✅ فحص VirusTotal | API عام مجاني للملفات المشبوهة |
   774→| ✅ توقيع callback_data | HMAC قصير لمنع التلاعب |
   775→| ✅ قائمة سوداء للمستخدمين | `is_blocked` في جدول `users` |
   776→
   777→### 9.2 الأداء
   778→
   779→| التحسين | التأثير |
   780→|---|---|
   781→| ✅ فهارس B-Tree + GIN | استعلامات < 10ms |
   782→| ✅ PgBouncer transaction mode | اتصالات متعددة من Workers |
   783→| ✅ Workers Cache API | تخزين مؤقت 60s للقراءات |
   784→| ✅ Cloudflare Queues | توزيع التعميمات على دفعات |
   785→| ✅ تطبيع النصوص مسبقاً | لا حساب عند البحث |
   786→| ✅ Pagination 8 أزرار/صفحة | استجابة سريعة + تجربة مستخدم جيدة |
   787→
   788→### 9.3 حدود Cloudflare Workers (مُدارة)
   789→
   790→| المورد | الحد المجاني | الاستراتيجية |
